# Introduction

Throw an exception in a Spring JDBC Template.

# Details

This attack only target JVMs identified as Spring Application. The original call is not executed.

# Compatibility

Verified with Spring Boot 2.7, 3.5 and 4.1, on the Java LTS releases each line supports (Java 8–17 for 2.7; 17–25 for 3.5 and 4.1).

# Parameters

| Parameter           | Description                                                                  | Default |
|---------------------|------------------------------------------------------------------------------|---------|
| Operation           | Which operation should be attacked?                                          | *       |
| Duration            | How long should the JDBC template call be intercepted to throw an exception? | 30s     |
| JDBC connection url | (optional) Which JDBC connection should be attacked?                         | *       |
| Erroneous Call Rate | (optional) How many percent of calls should trigger an exception?            | 100     |
