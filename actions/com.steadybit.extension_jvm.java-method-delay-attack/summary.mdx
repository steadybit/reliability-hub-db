# Introduction

Inject latency into any JVM based application.

# Details

Specify the fully qualified class name in the `Class Name` parameter. For the `Method Name` parameter, provide only the method name, don't include the full method signature.
If the targeted method is overloaded, all overloaded variants will be affected.

The delay is applied before the method executes.

# Compatibility

Verified on Java 8, 11, 17, 21 and 25 — on plain Java applications and on Spring Boot 2.7, 3.5 and 4.1.

# Parameters

| Parameter                      | Description                                                                             | Default |
|--------------------------------|-----------------------------------------------------------------------------------------|---------|
| Class Name                     | Which Java class should be attacked?                                                    |         |
| Method Name                    | Which public method should be attacked?                                                 |         |
| Duration                       | How long should the traffic be delayed?                                                 | 30s     |
| Delay                          | How much should the traffic be delayed?                                                 | 500ms   |
| Jitter                         | (optional) Random +-30% jitter to network delay                                         | false   |
| Validate class and method name | (optional) Should the action fail if the specified class and method could not be found? | true    |
