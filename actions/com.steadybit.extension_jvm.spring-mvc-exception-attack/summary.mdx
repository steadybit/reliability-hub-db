# Introduction

Injects a `RuntimeException` into a Spring MVC controller.

# Details

This attack only target JVMs identified as Spring Application.

The exception is thrown before the handler method is executed.

# Compatibility

Verified with Spring Boot 2.7, 3.5 and 4.1, on the Java LTS releases each line supports (Java 8–17 for 2.7; 17–25 for 3.5 and 4.1).

# Parameters

| Parameter           | Description                                                              | Default |
|---------------------|--------------------------------------------------------------------------|---------|
| Request Mapping     | Which request mapping pattern should be used to match the requests?      |         |
| Http Methods        | Which http methods should be used to match the requests?                 | *       |
| Duration            | How long should the MVC controller be intercepted to throw an exception? | 30s     |
| Erroneous Call Rate | (optional) What percentage of requests should trigger an exception?      | 100     |
